# ArtiSys Oficina v1.0.11

Esta versão verifica novas releases oficiais do GitHub na abertura do aplicativo e a cada **5 minutos** enquanto ele estiver executando. A edição comercial utiliza exclusivamente o instalador `-Commercial.exe`, com SHA-256 validado e instalação mediante confirmação do usuário. O núcleo gratuito continua independente de serviços pagos.

A tela de recuperação de senha da edição comercial informa que novos códigos valem **48 horas**. A Central Cloudflare mantém validade, tentativas e uso único; uma nova emissão invalida o código anterior.

Atualizações não apagam o banco PostgreSQL, arquivos locais, licenças ou usuários. O instalador comercial e a versão livre são validados separadamente no pipeline Windows.
